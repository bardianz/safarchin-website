# وب‌سایت معرفی راه‌چین

وب‌سایت فارسی و راست‌چین برای معرفی اپلیکیشن اندروید راه‌چین، با طراحی واکنش‌گرا و رنگ‌بندی هماهنگ با رابط اپلیکیشن.

## امکانات
- صفحه فرود فارسی با فونت وزیرمتن (Vazirmatn)
- بخش‌های ویژگی‌ها، نحوه کار، پرسش‌های متداول، معرفی توسعه‌دهنده و دانلود
- لینک دانلود مستقیم به صفحه راه‌چین در کافه‌بازار
- منوی موبایل و پرسش‌های متداول تعاملی
- متادیتای پایه برای موتورهای جست‌وجو و شبکه‌های اجتماعی
- بدون فریم‌ورک یا فرایند build؛ فقط HTML، CSS و JavaScript

## انتشار با GitHub Pages
۱. وارد تنظیمات مخزن و بخش **Pages** شو.
۲. در قسمت **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کن.
۳. شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کن.
۴. پس از پایان انتشار، آدرس نمایش‌داده‌شده در همان بخش را باز کن.

## پیش از انتشار عمومی
- بخش نظرات کاربران در حال حاضر محتوای نمایشی دارد و در خود صفحه نیز با عنوان نمونه مشخص شده است. قبل از انتشار نهایی، متن، عکس و امتیازها را با بازخوردهای واقعی و مورد تأیید کاربران جایگزین کن.
- تصاویر طبیعت و عکس‌های نمونه از Unsplash و فونت از Google Fonts بارگذاری می‌شوند؛ برای عملکرد بهتر روی اینترنت ضعیف می‌توان این منابع را در آینده داخل مخزن میزبانی کرد.
- توضیحات ویژگی‌ها را با امکانات نسخه منتشرشده اپلیکیشن تطبیق بده.
